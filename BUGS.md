| ID | Описание дефекта | Серьезность | Шаги воспроизведения | Фактический результат | Ожидаемый результат |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **1** | **Возможность удалить чужое объявление**<br>Отсутствует проверка принадлежности ресурса. | Критический | 1. Создать объявление Пользователем А (получить `id`).<br>2. Авторизоваться Пользователем Б.<br>3. Вызвать `DELETE /api/2/item/{id}` с токеном Пользователя Б. | Статус `200 OK`. Счетчики не могут быть меньше нуля. |
| **4** | **Сбой при отсутствии опционального блока statistics** | Средний| 1. Отправить POST `/api/1/item`.<br>2. Не передавать поле `statistics` в теле запроса. | Статус `400 Bad Request`. | Статус `200 OK` (или `201`). Блок должен быть опциональным, счетчики по умолчанию = 0. |
